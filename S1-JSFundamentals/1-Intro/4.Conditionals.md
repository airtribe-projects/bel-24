### Basic If

```
let age = 18;

if (age >= 18) {
  console.log("Adult");
}
```

### If Else

```
age = 15;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}
```


### Else if
```
let score = 82;

if (score >= 90) {
  console.log("A");
} else if (score >= 75) {
  console.log("B");
} else {
  console.log("C");
}
```


### Comparison Operator

| Operator | Meaning           |
| -------- | ----------------- |
| `>`      | Greater than      |
| `<`      | Less than         |
| `>=`     | Greater or equal  |
| `<=`     | Less or equal     |
| `==`     | Loose eqaulity    | 
| `===`    | Strict equality   |
| `!==`    | Strict inequality |

### Ternary Operator

Short conditional syntax.

```
age = 20;

let result = age >= 18 ? "Adult" : "Minor";
```

### Switch Case
Used for many exact matches.

```
let color = "red";

switch (color) {
  case "red":
    console.log("Stop");
    break;

  case "green":
    console.log("Go");
    break;

  default:
    console.log("Unknown");
}
```
